# Diva — Streetwear E-Commerce

A modern e-commerce website for a streetwear brand offering
fashion products for Women, Men.

Built with Angular, TypeScript, HTML, CSS, and REST APIs.

## Design System

Diva follows a consistent visual design system including:

- Burgundy primary color
- Beige and cream backgrounds
- Gold accent color
- Noto Serif typography
- Plus Jakarta Sans for UI text
- Consistent spacing and border radius


📄 [View Style Guide](./style-guide.md)


## Challenges

One of the main challenges was designing the application
architecture to separate customer functionality from the
admin dashboard.

This led to using reusable components, services, routing,
and role-based access control.
